Casca em C# (esboço) — LudrixHub

O que é: um Ludrix.exe nativo (.NET 8 + WebView2) que substitui pywebview, pythonnet,
tkinter e pystray. O núcleo em Python não muda: a casca abre `app\main.py --web 0`,
lê a porta em `data\instance.json` e mostra a interface no WebView2.

O que este esboço já faz
- janela com ícone Cristal, barra de título escura, cantos arredondados do Windows 11
- lembra tamanho/posição (data\host.json), tamanho mínimo 1000×660
- ícone na bandeja (clique = mostrar, menu Mostrar/Sair); X esconde na bandeja
- instância única: abrir de novo só traz a janela existente para a frente
- ponte JS: os comandos de janela que a interface já manda para /api/window
  (hide, show, minimize, maximize, close, quit, fullscreen) são atendidos pela casca;
  o resto continua indo para o Python
- links externos abrem no navegador padrão
- ao sair, pede ao núcleo para encerrar e, se não encerrar em 2,5 s, derruba o processo

O que falta para substituir o exe atual (fora do esboço)
- janela sem moldura com a barra de título do tema (hoje feita em Python/ctypes)
- menu de contexto, pop-ups e terminal como janelas filhas
- "Abrir com o Windows", atalho na área de trabalho, atualizador e reparo
- LudrixConsole como segunda janela da mesma casca
- Python embutido em runtime\ (hoje o esboço usa o Python instalado no PC)

Como compilar (Windows)
1. Instale o .NET SDK 8 (x64).
2. Rode casca\build-casca.bat → build\casca\Ludrix.exe (arquivo único, ~65 MB porque leva o .NET
   dentro; com <SelfContained>false</SelfContained> cai para ~2 MB, mas aí o PC precisa do
   .NET Desktop Runtime 8 instalado).
3. Copie esse Ludrix.exe para a pasta onde está app\ (a mesma do source) e abra.
   Requisito: Python 3.11+ instalado (ou runtime\pythonw.exe ao lado) e o WebView2
   Runtime, que todo Windows 10/11 atualizado já tem.

Conferido em 2026-10-03: compila e publica sem erros (dotnet 8.0.425); o exe em si só roda no Windows.
